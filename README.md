# 💊 Трекер Таблеток v2.0

Красивый минималистичный трекер приема лекарств с PWA поддержкой и уведомлениями.

## ✨ Возможности

- 💜 **Красивые анимации** - плавные переходы, конфетти, эффекты
- 📱 **PWA** - работает как нативное приложение
- 🔔 **Уведомления** - напоминания за 5 минут до приема
- 💾 **Автосохранение** - все данные в localStorage
- 📊 **Статистика** - прогресс дня в реальном времени
- 🎨 **Минимализм** - чистый современный дизайн

## 🚀 Установка

```bash
npm install
npm run dev
```

Откроется на http://localhost:5173

## 📱 Установка на телефон

1. Откройте приложение в браузере
2. iOS: Поделиться → На экран "Домой"
3. Android: Меню → Установить приложение

## 💝 Для твоей девушки

Приложение создано с любовью и вниманием к деталям:
- Нежные градиенты purple/pink
- Плавные анимации при каждом действии
- Конфетти при отметке принятых таблеток
- Сердечки и искорки повсюду
- Напоминания чтобы не забыть принять таблетки

## 🎯 Как использовать

1. Нажми "Добавить лекарство"
2. Заполни название, время и дозировку
3. Разрешь уведомления для напоминаний
4. Отмечай принятые таблетки галочкой
5. Смотри статистику и прогресс
